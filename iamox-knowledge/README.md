# IAMOx · Archivo de conocimiento

Archivo separado de la rama principal de código. Contiene solamente conocimientos enciclopédicos atribuidos a fuentes públicas, con fecha, revisión y pregunta/respuesta; nunca registros internos de DAMO, identidades, claves, telemetría, rutas, conversaciones privadas ni mensajes sin fuente.

Los mensajes de cada pulso permanecen temporalmente en DAMO. Solo se publican aquí los extractos sanitizados que tengan una fuente pública verificable, por lotes diarios y después de verificar el envío. Una respuesta documentada por una fuente **no** equivale a conocimiento validado independientemente. El código del metabolismo permanece en `/home/damo/IAMOX` y su estado local no se reconstruye desde este archivo.
